## 单位、生命与距离

- 玩家和敌方生命条件全部显式 `use_predicted=true`，无论源使用何值；这是用户推荐纠正。
- 源类型 `>100` 表示可辅助，不能误读成敌对。类型 0 覆盖不存在、死亡，以及不可攻击且不可辅助的对象，不只是目标不存在。
- 两坦克的有效目标，以及源规则要求的焦点，均需同时满足存在、存活、可攻击、不可辅助；具体组合复用现有条件，不新建分类插件。按各规则原位置引用，不能让该组合成为所有动作的隐藏门控。
- 仅迁移源原有距离条件；默认使用该动作技能的范围，不复用 LibRangeCheck，也不给无距离条件的动作增加门控。

- `IsSpellInRange` 可合法返回 nil，但本次没有游戏实测某一具体技能返回 nil；`SpellHasRange` 也不保证可以对指定单位有效检测，不能据此编造不支持技能列表。
